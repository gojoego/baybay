# Song Lyrics App

An interactive multilingual song lyrics and language-learning application.

## Features

- Song and artist search
- Side-by-side lyrics and translations
- Vocabulary and contextual explanations
- Saved songs and vocabulary collections

## Stack

Elixir, Phoenix, LiveView, Tailwind CSS, PostgreSQL, Ecto, and ExUnit.

## Deployment

- Hosting: Fly.io
- Planned URL: https://lyrics.moriahproject.org

## Status

Early development.
