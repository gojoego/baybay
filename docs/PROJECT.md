# Project Overview

## Vision

Help users understand foreign-language music through interactive lyrics, translations, vocabulary, and contextual explanations.

## MVP

- Search and select songs from sample data.
- Display lyrics and translations side by side.
- Support language selection.
- Persist song information in PostgreSQL.
- Provide a responsive, accessible interface.

## Future Features

- Music and licensed lyrics API integrations
- AI-assisted translations
- Grammar and vocabulary explanations
- User accounts and saved collections
- Synchronized lyrics
- Pronunciation assistance

## Constraints

- Zero additional development costs initially.
- Minimize recurring infrastructure costs.
- Reuse the existing moriahproject.org domain.
- Maintain application, authentication, and data isolation.
- Respect copyright and API licensing requirements.

MVP scope and future features are subject to refinement.
